# AI Chatbot for Mental Health Support

## Overview
This project creates an AI chatbot that offers emotional support using transformer models.

## Components
- chatbot.py: Core logic with DialoGPT-small model.
- app.py: Flask API backend serving chat response.
- frontend.py: Streamlit-based UI client.
- requirements.txt: Required Python packages.

## Usage
1. Run `python app.py` to start the backend.
2. Run `streamlit run frontend.py` to open the chat UI.
3. Chat with the bot and receive empathetic replies.

## Deployment
Can be deployed to Render or Replit following their deployment guides for Flask and Streamlit apps.

## Notes
Add safety filters to handle offensive user input.
